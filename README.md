# XR Interaction Project

## ソースコードの場所
/*
  -Assets/XR_Game/Scripts/
*/
## プロジェクト概要
/*
UnityとC#を使用し、XR環境におけるさまざまなインタラクション機能を実装したプロジェクトです。
授業でXRについて学んだことをきっかけに、ハードウェアとプログラムを連携させる技術に興味を持ち、実際に複数の機能を実装しながら理解を深めることを目的として制作しました。
*/


## Development Environment
/*
- Unity
- C#
- XR Interaction Toolkit
- OpenXR
*/

## 開発目的
/*
授業を通してXR技術に触れたことで、ハードウェアとソフトウェアがどのように連携して動作するのかに興味を持ちました。
そのため、Unity上でXRに関連するさまざまな機能を実際に実装し、それぞれの仕組みや使用方法を確認するために本プロジェクトに取り組みました。
*/


## 開発方法

/*
実装したい機能ごとに、関連するサンプルやプロジェクト、技術資料を調べ、それらを参考にしながら一つずつ実装しました。
各機能を実際に動作させながら、設定方法や機能同士の連携について学習しました。
*/


## 開発期間

/*
約5日以上
*/


## 実装・学習した機能
/*
### 1. HMD / Controller Tracking
HMDとControllerの位置や向きをXR空間内に反映する機能について学習し、実装しました。

### 2. Interactor / Interactable
InteractorとInteractableを利用し、XR Controllerからオブジェクトを選択・操作する仕組みを実装しました。

### 3. Locomotion System / Provider
Locomotion SystemとProviderを利用し、XR空間内でプレイヤーが移動するための仕組みについて学習しました。

### 4. Teleportation
指定した地点へプレイヤーが移動できるTeleportation機能を実装しました。

### 5. UI Interaction
XR Controllerを利用して、XR空間内に配置されたUIを操作できる機能を実装しました。

### 6. Haptic Feedback
Controllerに振動を発生させ、操作に対するフィードバックを与える機能を実装しました。

### 7. XR Socket Interactor
XR Socket Interactorを利用し、オブジェクトを特定の位置に配置・固定する機能を実装しました。

### 8. XR Offset Grab Interactable
オブジェクトを掴んだ位置や向きを基準として操作できる機能について学習し、実装しました。
*/


## 学んだこと
/*
本プロジェクトを通して、XR Interaction Toolkitを利用した基本的なXRインタラクションについて理解を深めることができました。
特に、Controllerなどのハードウェアからの入力をUnity上の処理と連携させることで、ハードウェアとプログラムがどのようにつながって動作するのかを実際に確認することができました。
また、実装したい機能ごとに必要な情報を自分で調べ、サンプルや技術資料を参考にしながら機能を完成させる経験を積むことができました。
*/
